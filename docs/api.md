# API

Interactive documentation is generated by FastAPI at `/docs`.

Authentication:

- `POST /api/auth/register`
- `POST /api/auth/login`
- `POST /api/auth/logout`
- `GET /api/auth/me`

Knowledge bases and members:

- `GET/POST /api/knowledge-bases`
- `GET/PATCH/DELETE /api/knowledge-bases/{id}`
- `GET/POST /api/knowledge-bases/{id}/members`
- `DELETE /api/knowledge-bases/{id}/members/{user_id}`

Documents:

- `GET /api/documents`
- `GET/POST /api/knowledge-bases/{id}/documents` (upload returns 202)
- `GET /api/documents/{id}`
- `GET /api/documents/{id}/status`
- `GET /api/documents/{id}/file`
- `DELETE /api/documents/{id}`
- `POST /api/documents/{id}/reindex`

Retrieval and chat:

- `POST /api/search`
- `POST /api/chat` (`stream: true` uses server-sent events)
- `GET/DELETE /api/conversations` and `GET /api/conversations/{id}`
- `POST /api/feedback`

Graph and admin:

- `GET /api/graph/entities`
- `GET /api/graph/entities/{id}`
- `POST /api/graph/query`
- `GET /api/dashboard`
- `GET /api/system/status`
- `GET /api/admin/stats`
- `GET /api/admin/failures`
- `GET /api/admin/audit-logs`
- `GET /api/admin/health`

Errors use `{ "error": { "code", "message", "request_id" } }`.
